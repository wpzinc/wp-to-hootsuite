# WordPress to Hootsuite Plugin

Welcome to the WordPress to Hootsuite Plugin repository on GitHub. Here you can view the plugin source code, review open issues, and see releases of the plugin.

**If you're not a developer, please download the plugin from [wordpress.org](https://wordpress.org/plugins/wp-to-hootsuite). Downloading and installing directly from GitHub will not work.**

## Support

If you are having issues setting up this plugin on your WordPress site, or have issues with WordPress to Hootsuite, please do the following:

* Check the [Documentation](https://www.wpzinc.com/documentation/)
* Review the [support forum](https://wordpress.org/support/plugin/wp-to-hootsuite/)
